# Security Policy

## Reporting

If you find a security issue in this repository, open a private security advisory on GitHub if available, or contact the maintainer through the repository owner profile.

## Scope

This repository contains documentation and templates. Security issues are most likely to involve accidental disclosure patterns, unsafe workflow advice, or examples that could encourage secret leakage.

## Public Release Rule

Do not contribute examples containing:

- Real credentials.
- Private file paths.
- Internal company names unless they are public.
- Proprietary source code.
- Logs with identifying data.
